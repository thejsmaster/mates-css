Mates-CSS

A pure CSS library with no JavaScript.

We don't flash, we deliver!

CSS library for all frameworks like React, Vue, Mates, Angular, Solid, Svelte, Lit. Even plain JS. It even comes with a design system.

A pure CSS library with no JavaScript. Style your HTML using the classes defined in this kit. Install mates-css and import it into your app component or root module in a frontend or fullstack application — or use the live CDN links.

Native tags (button, input, table…) are styled with no class. Classes are variants (.btn-primary) or the same look on a non-native host (<a class="btn">). Overlays stay closed until your app adds .open.

Install

Add the stylesheet once at the root of the app. After that, markup is enough — Mates CSS has no runtime.

npm install mates-css 
// src/main.tsx — root module
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import "mates-css";
import App from "./App";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);
// src/main.js — root module
import { createApp } from "vue";
import "mates-css";
import App from "./App.vue";

createApp(App).mount("#app");
// app entry — Mates JS
import "mates-css";
import { App } from "./app.js";

App.mount("#root");
// src/main.ts — root module
import { bootstrapApplication } from "@angular/platform-browser";
import { App } from "./app/app";
import "mates-css";

bootstrapApplication(App);
// src/index.jsx — root module
import { render } from "solid-js/web";
import "mates-css";
import App from "./App";

render(() => <App />, document.getElementById("root"));
// index.js — import once at the document root (not inside a shadow root)
import "mates-css";
import "./app.js";

// app.js
import { LitElement, html } from "lit";

class AppShell extends LitElement {
  createRenderRoot() { return this; } // light DOM so Mates classes apply
  render() {
    return html`<button class="btn-primary">Save</button>`;
  }
}
customElements.define("app-shell", AppShell);

Use with AI

Point an agent at the class contract, then let it build against mates-css. That name is the CSS library — not the Mates JS framework. If a widget is missing, the agent should compose native HTML and --m-* tokens — not invent class names or pull in another kit.

Contract: llms.txt · https://unpkg.com/mates-css/llms.txt. Project rules: AGENTS.md.

Build UI with mates-css. mates-css is a framework-agnostic
CSS library: it pre-styles native HTML (button, input, table, details, …)
and offers optional CSS classes. It has no JavaScript runtime.

Install: npm install mates-css then import "mates-css"
Read the class contract: https://unpkg.com/mates-css/llms.txt

Use only classes listed there. Native HTML first; classes are variants
(.btn-primary) or the same look on a non-native host (<a class="btn">).
Overlays (.modal .menu .pop .drawer .sheet .search): add class .open
Current item: class .selected (not .active, except drag-over on .drop).

If mates-css has no component, build it from scratch with native HTML,
var(--m-*) tokens, and .m-* utilities. use buit in classes whenever possible. Apply these classes to the native HTML elements using framework specific methods.

States

Mates CSS does not open overlays on focus or with a hidden checkbox. Your app toggles classes. This is the full state vocabulary.

Open overlays — add .open on the root: .modal, .menu, .pop, .drawer, .sheet, .search.

Selected — .selected on .tab, .sidenav-item, .list-item, .chip, .seg-item, .pick, .nav a, .subnav a, .toc a, .bnav-item, tr.

Collapsed — .collapsed on .shell shrinks the sidebar.

Active — .active on .drop while dragging files.

Done / current — .done and .current on .step; .current on a breadcrumb.

Disabled — native disabled on controls, or .disabled / .is-disabled on items.

el.classList.add("open");
el.classList.remove("open");
el.classList.toggle("open");
document.getElementById("m1").classList.add("open");
document.getElementById("m1").classList.remove("open");

// menu / popover / search — same .open class
menu.classList.toggle("open");

Tokens

Everything is a --m-* CSS variable on :root. Theme follows the OS (prefers-color-scheme) by default — do not set data-theme unless you need to override. Force a theme with data-theme="dark" or "light" on <html>.

Primary

Override tokens once; buttons, focus rings, and charts follow.

:root {
  --m-primary: #0172ad;
  --m-primary-h: #016091;
  --m-primary-a: #014e75;
  --m-on-primary: #ffffff;
  --m-r: 9px;
  --m-fs: 16px;
  --m-font: "Inter", sans-serif;
}

html[data-theme="dark"] { /* or prefers-color-scheme */ }

Button

Bare <button> and submit/reset inputs are styled with no class. Put .btn on a link. Variants stack on the same element: .btn-primary, .btn-dark, .btn-light, .btn-success, .btn-warning, .btn-danger, .btn-outline, .btn-soft, .btn-ghost, .btn-link. Sizes: .btn-sm .btn-lg .btn-block.
